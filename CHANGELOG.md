- Introduce append-only execution journal persistence with canonical evidence references and integrity hashes.
- Add event transformation and recorders for execution, claims, providers, reconciliation, operators, and campaigns.
- Add visibility-aware retrieval, Cockpit read models, integrity verification, and artifact rendering.
- Preserve the boundary that journal evidence records outcomes but never executes workflows or moves funds.
