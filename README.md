# x-journal

`x-journal` is the evidentiary journal package for the x-change Settlement Operating System.

It records durable journal entries for execution, claim, authorization, settlement, provider, reconciliation, operator, and campaign events. It does not decide business policy, move money, or own lifecycle truth.

## Namespace

```text
LBHurtado\XJournal
```

## Current status

Wave 2A package bootstrap is present. Runtime journal models, recorders, sinks, and transformers will be introduced through explicit slices.
